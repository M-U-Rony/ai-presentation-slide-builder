# ChatBubble Design System

## Overview

This is an Ai presentation slide builder app like gamma.ai. Where user comes give promt or slide content and select slide number and click generate Ai will first create the content of slide and send it is response


## Colors

- **Primary** (#22C55E): Green — sent messages, online status
- **Secondary** (#3B82F6): Blue — links, received messages accent
- **Tertiary** (#A855F7): Purple — reactions, premium features
- **Background** (#FFFFFF): Chat background
- **Surface** (#F3F4F6): Received message bubbles
- **Success** (#22C55E)
- **Warning** (#F59E0B)
- **Error** (#EF4444)
- **Info** (#3B82F6)

## Do's and Don'ts
- Do use the 20px large radius for all chat bubbles
- Don't apply large shadows to message bubbles
- Do ensure all interactive elements meet 44px minimum touch target on mobile
